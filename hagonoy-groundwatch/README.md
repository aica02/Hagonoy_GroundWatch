# Hagonoy GroundWatch

**A Community-Based Environmental Awareness Platform on Land Subsidence in Hagonoy, Bulacan**

Developed for Environmental Science (EnvirSci) Final Course Output.

## Features
- **3D Graphics & Interactive Model:** Three.js / React Three Fiber simulation showing ground subsidence and water sea level rise.
- **Vulnerability Hotspots Map:** Interactive map detailing affected barangays in Hagonoy (San Jose, Tibaguin, Mercado, etc.).
- **Interactive Knowledge Quiz:** Self-assessment tool with score tracking & instant explanations.
- **Incident Reporting Form:** Functional prototype form for residents to report tidal flooding and structural issues.
- **AI Environmental Assistant:** Interactive chatbot providing answers regarding land subsidence causes and solutions.
- **Academic Rigor:** Full reference listing formatted in APA 7th Edition.

## Tech Stack
- **Framework:** React + Vite
- **3D Graphics:** Three.js, `@react-three/fiber`, `@react-three/drei`
- **Styling:** Manual External CSS (Modular structure)
- **Icons:** Lucide React

## Setup & Running Locally

1. **Extract the ZIP package**
2. **Open terminal inside the project directory**
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Run the development server:**
   ```bash
   npm run dev
   ```
5. **Build for production:**
   ```bash
   npm run build
   ```
